## 系统要求

| 平台 | 版本要求 | 安装包 |
|---|---|---|
| macOS | 13.0+（Apple 芯片 / Intel） | `.dmg` |
| Windows | Windows 10/11（x64） | `.exe` |

## 下载安装

<Steps>
  <Step title="下载安装包">
    前往官网 [www.example.com/download](https://www.example.com/download) 获取对应平台的安装包。
  </Step>
  <Step title="安装">
    - **macOS**：打开 `.dmg`，将 OfficeBuddy 拖入「应用程序」。
    - **Windows**：双击 `.exe`，按向导完成安装。
  </Step>
  <Step title="首次启动">
    首次启动会引导你登录并选择默认工作目录。工作目录是智能体读写文件的根路径，建议选择一个专门的项目目录。
  </Step>
</Steps>

<Note>
macOS 首次启动如提示「无法验证开发者」，请在「系统设置 → 隐私与安全性」中点击「仍要打开」。
</Note>

## 更新

客户端支持应用内自动更新，也可以随时在官网重新下载最新版覆盖安装。
